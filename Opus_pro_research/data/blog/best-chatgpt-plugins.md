## What are ChatGPT plugins in 2026?

A ChatGPT plugin packages new abilities into a workflow. OpenAI's help center describes it as something that "can include one or more apps, skills, or both." In practice, a plugin lets ChatGPT do work it can't do alone: design a slide in Canva, pull a record from HubSpot, or edit a video.

- **Apps vs plugins.** An app connects ChatGPT to an outside service, such as Google Drive or Slack. A plugin can bundle one or more apps with skills, which are reusable instructions for a task.
- **One directory for ChatGPT and Codex.** ChatGPT and Codex share a single plugin directory, so a plugin you install can show up in both.
- **Where they run.** Plugins work in ChatGPT on the web, desktop and mobile, and in Codex in the desktop app. Some plugins are desktop-only.
- **What's new since DevDay.** OpenAI's DevDay on September 29, 2026 added plugin extensions, which let a plugin open from the ChatGPT sidebar, show interactive panels, and preview files.

OpenAI also announced on September 11, 2026 that it plans to retire custom GPTs and offer a migration path to plugins, so plugins are where new ChatGPT add-ons are headed.

## How to install a ChatGPT plugin

1. **Open Plugins.** Select Plugins in the ChatGPT sidebar on the web, desktop or mobile app.
2. **Pick a plugin.** Search or browse by category, then open its page to review what it does, the skills and apps it includes, and what it can access.
3. **Install it.** Select Install plugin. If the plugin connects to an account, such as Notion or HubSpot, ChatGPT asks you to sign in to that service.
4. **Use it.** ChatGPT uses installed plugins on its own when they're relevant. You can also call one directly by typing @ and its name, or by choosing it from the plus menu in the message box.

Whether you can install a given plugin depends on your ChatGPT plan, workspace, role and region, and many plugins need an account with the company behind them.
