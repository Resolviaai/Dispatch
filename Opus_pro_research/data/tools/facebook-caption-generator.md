# Facebook Caption Generator

When you pick a clip and a Facebook Page in OpusClip, our AI generates the description and hashtags for that post. The copy comes from the video you are actually publishing, and you edit it before it goes out.

One requirement worth knowing up front: we support Facebook Pages. Private Facebook Profiles and Facebook Groups are not supported.

## Why the caption comes with the clip

### It reads the video

Copy is generated for each clip and each destination, so the Facebook caption is written from that clip rather than a generic template.

### Editable before it posts

AI-generated titles, descriptions and hashtags stay editable in the posting window on web and on the iOS post page.

### On-screen captions too

Separate from the post copy, clips get auto subtitles with styling, emoji and keyword highlighting, downloadable as an .srt file.

## Copy per post, not one caption reused

Social copy generation runs for each clip and each selected destination, so the Facebook Page version is not a TikTok caption pasted across.

Post one clip to several accounts and each gets its own description and hashtags.

## Frequently Asked Questions

### Does OpusClip generate Facebook captions?

Yes. When you select a clip and a Facebook Page, our AI auto-generates the description and hashtags for that post, and you can edit them before publishing.

### Can I post to a Facebook Group or a personal profile?

No. We currently support connecting a Facebook Page only. Private Facebook Profiles and Facebook Groups are not supported, and a missing Page is the most common connection error.

### Is the caption the text on the video or the post text?

OpusClip produces both. The post description and hashtags are generated when you choose a destination, and separately each clip gets on-screen subtitles you can style and download as an .srt file.

### Can I edit captions on several clips at once?

Not at the moment. Our help centre states there is no bulk caption edit feature, so each clip is edited individually.
