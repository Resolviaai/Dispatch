# Dispatch landing page

Standalone React + TypeScript + Vite marketing site. All source and assets for this page live in this folder.

```powershell
npm install
npm run dev
```

Build and typecheck:

```powershell
npm run build
```

The public CTA points to the Dispatch GitHub releases page. The workflow preview is an illustration, not a screenshot of the shipped app. See `DESIGN_NOTES.md`, `VISUAL_DIRECTION.md`, and `ASSETS.md` for the design rationale and assets.
