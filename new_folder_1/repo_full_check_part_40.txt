## A. EXECUTIVE VERDICT

**VERDICT: INTEGRATION FIXES IMPLEMENTED — READY FOR COMPILATION & PHYSICAL DEVICE TESTING**

All critical architectural blockers and reliability defects uncovered in this audit have now been addressed with minimal, robust code modifications. The core pipeline from mobile capture to YouTube publishing is fully wired:

1. **Android CameraX Lifecycle Initialized (P0 - FIXED):** `CameraCaptureManager` now provides a coroutine-safe `bindLifecycle()` method. `MainActivity.kt` pre-binds CameraX immediately upon permission check or grant. `SegmenterEngine.kt` ensures the camera is bound before triggering segment recording, and safely cancels the session without infinite loops if hardware initialization ever fails.
2. **Publishing Outbox Worker Daemon Wired (P0 - FIXED):** `PublishingOutboxWorker` is implemented with a strict concurrency lock (`_processing_lock`) and integrated into `dispatch/main.py`. Approving a clip in `dispatch/web/app.py` triggers an immediate asynchronous publishing pass (`trigger_outbox_pass()`).
3. **Bridge Camera Switch Corrected (P0 - FIXED):** `DispatchNativeBridge.switchCamera()` now invokes `CameraCaptureManager.toggleLensFacing()` to switch between back and front camera, while `toggleTorch()` remains available on its own control.
4. **Segment Upload Reliability & Drain Loop (P1 - FIXED):** `YouTubeDirectUploadWorker.kt` implements a complete drain loop over `dao.getPendingUploadSegments()`, ensuring rolling segments are never stranded. The uploaded YouTube video ID is parsed from the API response and persisted into Room SQLite via `MIGRATION_1_2`. Duplicate uploads on network drops are prevented via `findExistingUploadByDispatchId()`.
5. **Cellular Upload Support (P1 - FIXED):** `SegmenterEngine.kt` now reads `pairingManager.isWifiOnlyEnabled` to select `NetworkType.CONNECTED` when Wi-Fi only is disabled.

Once these specific code wiring gaps are resolved, the pipeline architecture, database schemas, and media rendering contracts are structurally sound.

## D. CRITICAL FINDINGS (SEVERITY MATRIX)

### P0 — Blocker (Must Be Fixed for Minimal Pipeline Execution)

1. **Publishing Outbox Worker Never Launched**
   - **Location:** [`dispatch/main.py`](file:///c:/CODE/Dispatch/dispatch/main.py#L45-L66) & [`dispatch/web/app.py:handle_approve_clip()`](file:///c:/CODE/Dispatch/dispatch/web/app.py#L615-L624)
   - **Impact:** Approved clips are enqueued into SQLite `publishing_outbox` table with `status = 'queued'`, but no thread ever consumes the queue. Nothing is ever published to YouTube Shorts.
   - **Correction:** Launch `threading.Thread(target=watch_outbox_loop, name="PublishingOutboxThread", daemon=True).start()` in `dispatch/main.py`, or trigger an immediate asynchronous pass of `process_outbox_queue()` within `handle_approve_clip()`.

2. **Android CameraX Lifecycle Uninitialized at Recording Start**
   - **Location:** [`android/app/src/main/java/com/resolvia/dispatch/MainActivity.kt`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/MainActivity.kt#L60-L70), [`SegmenterEngine.kt:startSession()`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/recorder/SegmenterEngine.kt#L56-L61), [`CameraCaptureManager.kt:startSegmentRecording()`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/recorder/CameraCaptureManager.kt#L483-L487)
   - **Impact:** `MainActivity.kt` no longer binds `CameraCaptureManager` to a native layout. Calling `startRecording()` from WebView launches `RecordingForegroundService`, but immediately calls `startSegmentRecording()` before the service or `VideoCapture` is initialized. Throws `IllegalStateException("VideoCapture not initialized")` and aborts.
   - **Correction:** Initialize and pre-bind `CameraCaptureManager` during `MainActivity.onCreate()` (binding VideoCapture to the activity lifecycle or ensuring `startSession()` awaits `onReady` callback from `bindToService` before triggering `startNextSegment`).

3. **Bridge Camera Switch Inversion**
   - **Location:** [`android/app/src/main/java/com/resolvia/dispatch/bridge/DispatchNativeBridge.kt:switchCamera()`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/bridge/DispatchNativeBridge.kt#L87-L97)
   - **Impact:** Tapping the "Switch Camera" button in the React UI toggles the hardware torch instead of toggling the camera lens between front and back.
   - **Correction:** Replace `cameraCaptureManager.toggleTorch()` with `cameraCaptureManager.toggleLensFacing(activity)` or lens toggle delegate in `switchCamera()`.

### P1 — Major (Causes Incomplete Data, Dropped Uploads, or Stalls)

4. **WorkManager `ExistingWorkPolicy.KEEP` Drops Segment Uploads**
   - **Location:** [`android/app/src/main/java/com/resolvia/dispatch/recorder/SegmenterEngine.kt:triggerYouTubeUpload()`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/recorder/SegmenterEngine.kt#L210-L215)
   - **Impact:** `triggerYouTubeUpload()` enqueues unique work with `ExistingWorkPolicy.KEEP`. When segment 1 is uploading (which takes several minutes), segment 2 rolls. The enqueue request for segment 2 is silently dropped by WorkManager. If the upload worker queried `getPendingUploadSegments()` only at the start of `doWork()`, segment 2 remains stuck in `QUEUED_FOR_UPLOAD`.
   - **Correction:** In `YouTubeDirectUploadWorker.doWork()`, wrap the processing loop in a `while (true)` check that re-queries `dao.getPendingUploadSegments()` until the queue is genuinely empty before exiting with `Result.success()`.

5. **Uploaded YouTube Video ID Not Persisted to Mobile Database**
   - **Location:** [`android/app/src/main/java/com/resolvia/dispatch/sync/YouTubeDirectUploadWorker.kt:uploadToYouTubeDirect()`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/sync/YouTubeDirectUploadWorker.kt#L219-L224)
   - **Impact:** When YouTube returns HTTP 200/201 on the final chunk, the response contains `{"id": "VIDEO_ID"}`. The worker parses `totalBytes` but discards the video ID. `SegmentEntity` in Room lacks a column for `youtubeVideoId`. Mobile UI cannot show a direct YouTube link for uploaded raw sessions.
   - **Correction:** Parse `video_id` from the HTTP 200/201 response JSON and persist it to the segment record.

6. **Unmetered Network Constraint Blocks Mobile Data Uploads**
   - **Location:** [`android/app/src/main/java/com/resolvia/dispatch/recorder/SegmenterEngine.kt:triggerYouTubeUpload()`](file:///c:/CODE/Dispatch/android/app/src/main/java/com/resolvia/dispatch/recorder/SegmenterEngine.kt#L201-L203)
   - **Impact:** Network constraint is hardcoded to `NetworkType.UNMETERED`. When the creator records away from home using cellular data (4G/5G), uploads remain blocked until connecting to Wi-Fi. The toggle in `SettingsScreen.tsx` (`wifiOnly`) is not read by `SegmenterEngine`.
   - **Correction:** Read the user's `wifiOnly` preference from `SharedPreferences` in `SegmenterEngine.triggerYouTubeUpload()`; use `NetworkType.CONNECTED` when Wi-Fi-only is disabled.

### P2 — Quality of Life & Observability

7. **Infinite Ingestion Retries Without Backoff for Corrupt Remote Videos**
   - **Location:** [`dispatch/youtube_inbox/poller.py:poll_once()`](file:///c:/CODE/Dispatch/dispatch/youtube_inbox/poller.py#L106-L130)
   - **Impact:** If `catcher.ingest_video()` fails (e.g., video deleted from YouTube or processing permanently failed), status is marked `FAILED`. On the next poll (10m later), `is_youtube_video_processed()` returns `False` for `FAILED`, causing an infinite re-attempt loop.
   - **Correction:** Add a `retry_count` cap (e.g., max 5 attempts) and exponential backoff (`next_attempt_at`) to `youtube_inbox` ingestion failures.

8. **Asset Freshness in Android Assets**
   - **Location:** [`android/app/src/main/assets/web/`](file:///c:/CODE/Dispatch/android/app/src/main/assets/web/)
   - **Impact:** The packaged web assets reflect an earlier build. Any recent changes made in `frontend/src/` will not appear in the installed Android APK unless `npm run build` is run before `gradlew assembleDebug`.
   - **Correction:** Document and execute the Vite compilation step during mobile packaging.

## E. DATABASE & LIFECYCLE RECOVERY AUDIT

### State Machines

#### 1. YouTube Inbox (`youtube_inbox.status`)
```text
DISCOVERED ➔ DOWNLOADING ➔ VALIDATING ➔ DOWNLOADED ➔ WAITING_FOR_TRANSCRIPT ➔ TRANSCRIBED ➔ ANALYZING ➔ CLIPS_DEFINED ➔ COMPLETED
                                      ↳ (error) ➔ FAILED
```
- **Durable Progress:** Every transition is written to SQLite before initiating the next step.
- **Worker Recovery:** If the daemon crashes:
  - `DOWNLOADED` records are re-scanned on boot by `TranscriptionWorker`.
  - `WAITING_FOR_TRANSCRIPT` records resume their deadline countdown.
  - `TRANSCRIBED` records are re-scanned on boot by `HighlightWorker`.
  - Auto-rendered clips are guarded by file-existence checks to prevent redundant FFmpeg re-encodes.

#### 2. Clips (`clips.status`)
```text
ready_review ➔ approved ➔ published
            ↳ rejected
```
- **Stale Render Safeguard:** In `dispatch/web/app.py:list_clips()`, `is_render_stale` is computed dynamically (`clip.layout_mode != clip.rendered_layout_mode`). If the user modifies framing in the UI, `handle_approve_clip()` checks if the rendered file matches the target layout; if not, it automatically re-renders with FFmpeg before approval.

#### 3. Publishing Outbox (`publishing_outbox.status`)
```text
queued ➔ uploading ➔ published
      ↳ (missing auth) ➔ blocked_needs_auth
      ↳ (failure) ➔ queued (attempt_count < 4) ➔ failed
```
- **Idempotency:** Unique index on `idempotency_key` (`{clip_id}_{platform}`) prevents duplicate entries.

### Media Retention & Cleanup Policy
- **Phone Media:** Raw MP4 files in `/storage/emulated/0/DCIM/Dispatch/` are **never deleted** upon upload. Only the Outbox queue entry is cleared.
- **PC Ingestion:** Source videos in `storage/youtube_inbox/{video_id}.mp4` are **never deleted** during or after processing.
- **Rendered Clips:** When an outbox job completes, `check_and_finalize_clip()` logs that media is preserved. Rendered MP4 files in `storage/clips/` remain intact for archival and re-posting.
- **Zero Premature Deletion:** No media is deleted on job submission, retry, or failure.

export const App: React.FC = () => {
  const [currentTab, setCurrentTab] = useState<TabType>('record');
  const [pcHost, setPcHost] = useState<string>(() => {
    if (typeof window !== 'undefined') {
      const native = (window as any).DispatchBridge?.getPcHost?.()?.trim();
      if (native) return native;
    }
    if (typeof localStorage !== 'undefined') {
      const saved = localStorage.getItem('dispatch_pc_host');
      if (saved) return saved;
    }
    if (typeof window !== 'undefined' && (
      window.location.protocol === 'file:' ||
      window.location.hostname === 'appassets.androidplatform.net' ||
      !!(window as any).DispatchBridge
    )) {
      return '192.168.0.200:8000';
    }
    return 'localhost:8000';
  });
  const [isMobileFrame, setIsMobileFrame] = useState<boolean>(() => {
    if (typeof window !== 'undefined') {
      if ((window as any).DispatchBridge) return true;
      const saved = localStorage.getItem('dispatch_view_mode');
      if (saved === 'mobile') return true;
      if (saved === 'desktop') return false;
      return window.innerWidth < 1024;
    }
    return false;
  });
  
  const [recordings, setRecordings] = useState<RecordingItem[]>([]);
  const [isYouTubeConnected, setIsYouTubeConnected] = useState<boolean>(false);
  const [isEditorOpen, setIsEditorOpen] = useState<boolean>(false);
  const [sessionFilter, setSessionFilter] = useState<string | null>(null);

  const handleNavigateToClips = (sessionId?: string) => {
    setSessionFilter(sessionId || null);
    setCurrentTab('clips');
  };

  const [isPcOnline, setIsPcOnline] = useState<boolean>(false);

  // Autonomous Connection Healthcheck & Dynamic Self-Healing
  useEffect(() => {
    let isCancelled = false;

    const probeConnection = async () => {
      // 1. Probe the current configured pcHost
      try {
        const controller = new AbortController();
        const timeoutId = setTimeout(() => controller.abort(), 2500);
        const res = await fetch(apiUrl('/api/status', pcHost), { signal: controller.signal });
        clearTimeout(timeoutId);
        if (res.ok) {
          if (!isCancelled) setIsPcOnline(true);
          return;
        }
      } catch {
        // Current host did not respond
      }

      if (!isCancelled) setIsPcOnline(false);

      // 2. If running on mobile/native WebView and current host failed, probe static LAN anchor
      const isMobileOrNative = typeof window !== 'undefined' && (
        !!(window as any).DispatchBridge ||
        window.location.hostname === 'appassets.androidplatform.net' ||
        window.location.protocol === 'file:'
      );

      const staticAnchor = '192.168.0.200:8000';
      if (isMobileOrNative && pcHost !== staticAnchor) {
        try {
          const controller = new AbortController();
          const timeoutId = setTimeout(() => controller.abort(), 2500);
          const res = await fetch(`http://${staticAnchor}/api/status`, { signal: controller.signal });
          clearTimeout(timeoutId);
          if (res.ok) {
            console.info(`[Dispatch] Auto-healed connection from offline host (${pcHost}) to static anchor (${staticAnchor})`);
            Bridge.setPcHost(staticAnchor);
            if (!isCancelled) {
              setPcHost(staticAnchor);
              setIsPcOnline(true);
            }
          }
        } catch {
          // Static anchor also unreachable
        }
      }
    };

    probeConnection();
    const interval = setInterval(probeConnection, 8000);
    return () => {
      isCancelled = true;
      clearInterval(interval);
    };

        if (res.ok) {
          const data = await res.json();
          setIsYouTubeConnected(!!data.youtube?.connected);
        }
      } catch {

          setIsYouTubeConnected(status.connected);
        }
      }

    checkYouTube();
    const interval = setInterval(checkYouTube, 6000);

  }, [pcHost]);

  };

    setRecordings(prev => prev.map(rec => {
      if (rec.segmentId === segmentId) {
        return { ...rec, status, ...(extra || {}) };
      }
      return rec;
    }));
  };

  const handleRetryUpload = async (segmentId: string) => {
    if (Bridge.isAvailable()) {
      Bridge.retryUpload(segmentId);
    }
    setRecordings(prev => prev.map(rec => {
      if (rec.segmentId === segmentId) {

import React, { useEffect, useState } from 'react'
import { supabase, currentSession, signIn, signUp, signOut } from './supabase'
import type { Session } from '@supabase/supabase-js'

/**
 * Email/password gate for the whole app (Supabase Auth). Session persists across
 * app restarts. Renders children only for an authenticated session.
 */
export function AuthGate({ children }: { children: (session: Session) => React.ReactNode }) {
  const [session, setSession] = useState<Session | null>(null)
  const [loading, setLoading] = useState(true)
  const [mode, setMode] = useState<'signin' | 'signup'>('signin')
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [error, setError] = useState<string | null>(null)
  const [notice, setNotice] = useState<string | null>(null)
  const [busy, setBusy] = useState(false)

  useEffect(() => {
    currentSession().then(s => { setSession(s); setLoading(false) })
    const { data: sub } = supabase.auth.onAuthStateChange((_e, s) => setSession(s))
    return () => sub.subscription.unsubscribe()
  }, [])

  if (loading) {
    return (
      <div className="min-h-screen flex items-center justify-center bg-background">
        <span className="text-text-muted text-sm">Loading…</span>
      </div>
    )
  }

  if (session) {
    return <>{children(session)}</>
  }

  const submit = async (e: React.FormEvent) => {
    e.preventDefault()
    setBusy(true); setError(null); setNotice(null)
    try {
      if (mode === 'signup') {
        const { error } = await signUp(email.trim(), password)
        if (error) throw error
        setNotice('Account created. You are signed in.')
      } else {
        const { error } = await signIn(email.trim(), password)
        if (error) throw error
      }
    } catch (err: any) {
      setError(err.message || 'Authentication failed')
    } finally {
      setBusy(false)
    }
  }

  return (
    <div className="min-h-screen flex items-center justify-center bg-background px-4">
      <form onSubmit={submit} className="w-full max-w-sm bg-surface-100 border border-border rounded-2xl p-6">
        <div className="flex items-center gap-3 mb-6">
          <span className="w-9 h-9 rounded-lg bg-primary flex items-center justify-center">
            <svg width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="#fff" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" aria-hidden="true"><polygon points="5 3 19 12 5 21 5 3"/></svg>
          </span>
          <h1 className="text-lg font-semibold text-text-main">Dispatch</h1>
        </div>
        <h2 className="text-sm font-medium text-text-main mb-4">
          {mode === 'signin' ? 'Sign in to your account' : 'Create your account'}
        </h2>
        <label htmlFor="auth-email" className="block text-xs text-text-secondary mb-1">Email</label>
        <input id="auth-email" type="email" required autoComplete="email" value={email}
          onChange={e => setEmail(e.target.value)}
          className="w-full min-h-[44px] px-3 rounded-lg bg-surface-200 border border-border text-text-main mb-3" />
        <label htmlFor="auth-password" className="block text-xs text-text-secondary mb-1">Password</label>
        <input id="auth-password" type="password" required autoComplete={mode === 'signup' ? 'new-password' : 'current-password'}
          minLength={8} value={password} onChange={e => setPassword(e.target.value)}
          className="w-full min-h-[44px] px-3 rounded-lg bg-surface-200 border border-border text-text-main mb-4" />
        {error && <p role="alert" className="text-xs text-[#EF4444] mb-3">{error}</p>}
        {notice && <p role="status" className="text-xs text-[#22C55E] mb-3">{notice}</p>}
        <button type="submit" disabled={busy || !email || password.length < 8}
          className="w-full min-h-[48px] rounded-lg bg-primary text-white font-semibold active:scale-[0.98] transition-all duration-150 disabled:opacity-40">
          {busy ? 'Please wait…' : mode === 'signin' ? 'Sign in' : 'Create account'}
        </button>
        <div className="flex items-center justify-between mt-4">
          <button type="button" onClick={() => { setMode(m => m === 'signin' ? 'signup' : 'signin'); setError(null); setNotice(null) }}
            className="text-xs text-primary-h hover:underline">
            {mode === 'signin' ? 'Need an account? Sign up' : 'Have an account? Sign in'}
          </button>
          {session === null && (
            <button type="button" onClick={() => signOut()} className="text-xs text-text-muted hover:underline">Clear session</button>
          )}
        </div>
      </form>
    </div>
  )
}

  const base = getApiBaseUrl(pcHost);
  if (!base) return path;
  const cleanPath = path.startsWith('/') ? path : `/${path}`;
  return `${base}${cleanPath}`;
}

export function getAuthHeaders(custom?: Record<string, string>): Record<string, string> {
  const headers: Record<string, string> = {
    'Content-Type': 'application/json',
    ...(custom || {}),
  };
  const token = typeof window !== 'undefined' ? (window as any).DispatchBridge?.getAuthToken?.() : null;
  if (token && token.trim().length > 0) {
    headers['x-auth-token'] = token.trim();
  }
  return headers;
}

import type { ExposureInfo, ExposureResultEvent, FocusResultEvent, CameraStateEvent } from '../bridge';

export type FocusStatus = 'idle' | 'focusing' | 'locking' | 'unlocking' | 'success' | 'failed' | 'locked' | 'uncertain';

export interface FocusExposureState {
  x: number;
  y: number;
  screenNormX: number;
  screenNormY: number;

  pointerId: number;
  originX: number;
  originY: number;

  isExposureSlider: boolean;
}

export function beginPointerSession(
  pointerId: number,
  x: number,
  y: number,
  startExposureIndex: number,
  isExposureSlider: boolean
): PointerSession {
  return { pointerId, originX: x, originY: y, startExposureIndex, isExposureSlider };
}

export function exposureIndexForPointerMove(
  session: PointerSession | null,
  pointerId: number,
  x: number,
  y: number,
  exposure: ExposureInfo,
  totalDragDistancePx = 160
): number | null {
  if (!session || session.pointerId !== pointerId || !session.isExposureSlider || !exposure.isSupported) {
    return null;
  }

  const range = Math.max(1, exposure.maxIndex - exposure.minIndex);
  const indexOffset = (-(y - session.originY) / totalDragDistancePx) * range;
  return Math.min(
    exposure.maxIndex,
    Math.max(exposure.minIndex, Math.round(session.startExposureIndex + indexOffset))
  );
}

export function endPointerSession(session: PointerSession | null, pointerId: number): PointerSession | null {
  return session?.pointerId === pointerId ? null : session;
}

export function applyExposureResult(
  currentIndex: number,
  result: ExposureResultEvent
): { index: number; error: string | null } {
  if (result.success && Number.isInteger(result.index)) {
    return { index: result.index, error: null };
  }
  return {
    index: currentIndex,
    error: result.error || 'Camera did not apply the exposure change',
  };
}

export function applyFocusResult(
  current: FocusExposureState | null,
  result: FocusResultEvent
): FocusExposureState | null {
  if (!current || !Number.isFinite(result.triggerId) || current.triggerId !== result.triggerId) {
    return current;
  }

  if (result.lockStateUncertain) {
    return {
      ...current,
      status: 'uncertain',
      isLocked: false,
      hasAf: result.hasAf ?? current.hasAf,
      hasAe: result.hasAe ?? current.hasAe,
      error: result.error || 'Camera lock state is uncertain; unlock to recover safely.',
    };
  }

  const canConfirmDelayedLock = (current.status === 'failed' || current.status === 'uncertain') && result.success && result.isLocked;
  const lockConfirmed = result.success && result.isLocked && (result.hasAf === true || result.hasAe === true);
  if (current.status === 'locking' || canConfirmDelayedLock) {
    return {
      ...current,
      status: result.lockStateUncertain ? 'uncertain' : lockConfirmed ? 'locked' : 'failed',
      isLocked: lockConfirmed,
      hasAf: result.hasAf ?? current.hasAf,
      hasAe: result.hasAe ?? current.hasAe,
      error: result.error || (lockConfirmed ? undefined : 'Camera did not confirm the AE/AF lock'),
    };
  }

  if (current.status === 'unlocking') return current;

  return {
    ...current,
    status: result.success && !result.isLocked ? 'success' : 'failed',
    isLocked: false,
    hasAf: result.hasAf ?? current.hasAf,
    hasAe: result.hasAe ?? current.hasAe,
    error: result.success ? undefined : (result.error || 'Camera focus failed'),
  };
}

export function markLockAttemptTimedOut(
  current: FocusExposureState | null,
  triggerId: number
): FocusExposureState | null {
  if (!current || current.triggerId !== triggerId || current.status !== 'locking') return current;
  return {
    ...current,
    status: 'failed',
    isLocked: false,
    error: 'Lock confirmation timed out; resetting camera focus state',
  };
}

export function applyUnlockResult(
  current: FocusExposureState | null,
  success: boolean
): FocusExposureState | null {
  if (!current) return null;
  if (success) {
    return { ...current, status: 'idle', isLocked: false, hasAf: false, hasAe: false, error: undefined };
  }
  return {
    ...current,
    status: current.isLocked ? 'locked' : current.status === 'unlocking' ? 'uncertain' : current.status === 'uncertain' ? 'uncertain' : 'failed',
    error: 'Camera did not confirm unlock. Try again.',
  };
}

export function applyNativeLockState(
  current: FocusExposureState | null,
  isAeAfLocked: boolean,
  nativeState?: Pick<CameraStateEvent, 'isAeLocked' | 'isAfLocked' | 'isAeAfLockUncertain'>
): FocusExposureState | null {
  if (!current) return current;
  const hasKnownChannel = current.hasAe || current.hasAf;
  const hasAe = nativeState?.isAeLocked ?? (isAeAfLocked ? (hasKnownChannel ? current.hasAe : true) : false);
  const hasAf = nativeState?.isAfLocked ?? (isAeAfLocked ? (hasKnownChannel ? current.hasAf : true) : false);
  if (nativeState?.isAeAfLockUncertain) {
    return { ...current, status: 'uncertain', isLocked: false, hasAe, hasAf, error: 'Camera lock state could not be confirmed; unlock to recover safely.' };
  }
  if (isAeAfLocked) {
    return { ...current, status: 'locked', isLocked: true, hasAe, hasAf, error: undefined };
  }
  if (current.status === 'locking') return current;
  if (current.isLocked || current.status === 'locking' || current.status === 'unlocking') {
    return { ...current, status: current.status === 'unlocking' ? 'idle' : current.status, isLocked: false, hasAe: false, hasAf: false };
  }
  return current;
}

export function isCameraLifecycleTransition(
  previous: CameraStateEvent,
  next: CameraStateEvent
): boolean {
  return previous.lensFacing !== next.lensFacing || next.status !== 'ready';
}

import { CaptionTrack, CaptionGroup, StyleConfig, LayoutConfig, AnimationConfig } from './types';

export type StyleSection =
  | 'font'
  | 'color'
  | 'text'
  | 'stroke'
  | 'glow'
  | 'background'
  | 'shadow'
  | 'spacing'
  | 'bold_italic'
  | 'case'
  | 'alignment'
  | 'animation'
  | 'templates'
  | 'layout';

export interface ApplyToAllResult {
  nextTrack: CaptionTrack;
  affectedCount: number;
}

/**
 * Extracts only the properties belonging to the specified section from a source group.
 */
export function extractSectionProperties(
  sourceGroup: CaptionGroup,
  track: CaptionTrack,
  section: StyleSection
): {
  stylePatch?: Partial<StyleConfig>;
  layoutPatch?: Partial<LayoutConfig>;
  animationPatch?: Partial<AnimationConfig>;
} {
  const targetStyle = sourceGroup.style || track.default_style;
  const targetLayout = sourceGroup.layout || track.default_layout;
  const targetAnimation = sourceGroup.animation || track.default_animation;

  switch (section) {
    case 'font':
      return {
        stylePatch: {
          font_family: targetStyle.font_family,
          font_size: targetStyle.font_size,
          font_weight: targetStyle.font_weight,
          letter_spacing: targetStyle.letter_spacing,
          line_height: targetStyle.line_height,
          text_transform: targetStyle.text_transform,
        },
      };

    case 'color':
      return {
        stylePatch: {
          primary_color: targetStyle.primary_color,
          opacity: targetStyle.opacity,
          text_opacity: targetStyle.text_opacity,
          ...(sourceGroup.type !== 'text' ? {
            highlight_color: targetStyle.highlight_color,
            highlight_enabled: targetStyle.highlight_enabled,
          } : {}),
        },
      };

    case 'text':
      return {
        stylePatch: {
          primary_color: targetStyle.primary_color,
          text_opacity: targetStyle.text_opacity,
          font_size: targetStyle.font_size,
          opacity: targetStyle.opacity,
          font_weight: targetStyle.font_weight,
          font_style: targetStyle.font_style,
          underline: targetStyle.underline,
          text_transform: targetStyle.text_transform,
          ...(sourceGroup.type !== 'text' ? {
            highlight_color: targetStyle.highlight_color,
            highlight_enabled: targetStyle.highlight_enabled,
          } : {}),
        },
      };

    case 'stroke':
      return {
        stylePatch: {
          outline_enabled: targetStyle.outline_enabled,
          outline_color: targetStyle.outline_color,
          outline_width: targetStyle.outline_width,
          outline_opacity: targetStyle.outline_opacity,
        },
      };

    case 'glow':
      return {
        stylePatch: {
          glow_enabled: targetStyle.glow_enabled,
          glow_color: targetStyle.glow_color,
          glow_blur: targetStyle.glow_blur,
          glow_opacity: targetStyle.glow_opacity,
        },
      };

    case 'background':
      return {
        stylePatch: {
          background_enabled: targetStyle.background_enabled,
          background_mode: targetStyle.background_mode,
          background_color: targetStyle.background_color,
          background_opacity: targetStyle.background_opacity,
          background_padding_x: targetStyle.background_padding_x,
          background_padding_y: targetStyle.background_padding_y,
          background_corner_radius: targetStyle.background_corner_radius,
          background_offset_x: targetStyle.background_offset_x,
          background_offset_y: targetStyle.background_offset_y,
          background_width: targetStyle.background_width,
          background_height: targetStyle.background_height,
        },
      };

    case 'shadow':
      return {
        stylePatch: {
          shadow_enabled: targetStyle.shadow_enabled,
          shadow_color: targetStyle.shadow_color,
          shadow_offset_x: targetStyle.shadow_offset_x,
          shadow_offset_y: targetStyle.shadow_offset_y,
          shadow_blur: targetStyle.shadow_blur,
          shadow_opacity: targetStyle.shadow_opacity,
          shadow_distance: targetStyle.shadow_distance,
          shadow_angle: targetStyle.shadow_angle,
        },
      };

    case 'spacing':
      return {
        stylePatch: {
          letter_spacing: targetStyle.letter_spacing,
          line_height: targetStyle.line_height,
        },
        layoutPatch: {
          alignment: targetLayout.alignment,
          scale: targetLayout.scale,
        },
      };

    case 'bold_italic':
      return {
        stylePatch: {
          font_weight: targetStyle.font_weight,
          font_style: targetStyle.font_style,
          underline: targetStyle.underline,
        },
      };

    case 'case':
      return {
        stylePatch: {
          text_transform: targetStyle.text_transform,
        },
      };

    case 'alignment':
      return {
        layoutPatch: {
          alignment: targetLayout.alignment,
          max_width: targetLayout.max_width,
          max_lines: targetLayout.max_lines,
        },
      };

    case 'layout':
      return {
        layoutPatch: {
          position_x: targetLayout.position_x,
          position_y: targetLayout.position_y,
          scale: targetLayout.scale,
          ...(targetLayout.rotation !== undefined ? { rotation: targetLayout.rotation } : {}),
          ...(targetLayout.alignment !== undefined ? { alignment: targetLayout.alignment } : {}),
          ...(targetLayout.max_width !== undefined ? { max_width: targetLayout.max_width } : {}),
          ...(targetLayout.max_lines !== undefined ? { max_lines: targetLayout.max_lines } : {}),
        },
      };

    case 'animation':
      return {
        animationPatch: {
          type: targetAnimation.type,
          duration_ms: targetAnimation.duration_ms,
          active_scale: targetAnimation.active_scale,
          easing: targetAnimation.easing,
          enter: targetAnimation.enter ? { ...targetAnimation.enter } : undefined,
          active_word: targetAnimation.active_word ? { ...targetAnimation.active_word } : undefined,
          exit: targetAnimation.exit ? { ...targetAnimation.exit } : undefined,
          loop: targetAnimation.loop ? { ...targetAnimation.loop } : undefined,
        },
      };

    case 'templates':
      return {
        stylePatch: { ...targetStyle },
        animationPatch: { ...targetAnimation },
      };

    default:
      return {};
  }

/**
 * One-time action to apply ONLY the properties of the given section
 * from the target group to every eligible text/caption element in the clip.
 * 
 * Invariants:
 * 1. Only changed properties of the current section propagate.
 * 2. Unrelated section properties (colors, strokes, shadows, animations, positions) remain intact.
 * 3. Never applies to audio, video overlays, or voiceovers.
 * 4. Word-level overrides and timestamps are 100% preserved.
 * 5. Not a persistent mode — future edits remain strictly local.
 */
export function applySectionStylesToTrack(
  track: CaptionTrack | null,
  targetGroupId: string | null,
  section: StyleSection
): ApplyToAllResult {
  if (!track || !track.groups || track.groups.length === 0) {
    return { nextTrack: track as CaptionTrack, affectedCount: 0 };
  }

  const targetGroup = (targetGroupId ? track.groups.find((g) => g.id === targetGroupId) : null) ||
    track.groups.find((g) => !g.type || g.type === 'caption') ||
    track.groups.find((g) => g.type === 'text') ||
    track.groups[0];

  if (!targetGroup) {
    return { nextTrack: track, affectedCount: 0 };
  }

  const { stylePatch, layoutPatch, animationPatch } = extractSectionProperties(
    targetGroup,
    track,
    section
  );

  let affectedCount = 0;

  const updatedGroups = track.groups.map((grp) => {
    // Restrict strictly based on target layer type:
    // Text layers apply ONLY to other text layers.
    // Captions apply ONLY to other captions.
    // Audio and overlay layers are NEVER affected.
    const isTargetText = targetGroup.type === 'text';
    const isEligible = isTargetText
      ? grp.type === 'text'
      : (!grp.type || grp.type === 'caption');

    if (!isEligible) {
      return grp;
    }

    affectedCount++;
    return {
      ...grp,
      style: stylePatch ? { ...(grp.style || track.default_style), ...stylePatch } : grp.style,
      layout: layoutPatch ? { ...(grp.layout || track.default_layout), ...layoutPatch } : grp.layout,
      animation: animationPatch ? { ...(grp.animation || track.default_animation), ...animationPatch } : grp.animation,
    };
  });

  const nextTrack: CaptionTrack = {
    ...track,
    groups: updatedGroups,
  };

  return { nextTrack, affectedCount };
}
